# Step 8~9 공공데이터 API 준비

현재 프로젝트는 `USE_MOCK_DATA=true`인 수업용 모의 실행 상태입니다.

## Step 8 — 실제 계정에서 해야 하는 작업

1. 공공데이터포털에 로그인합니다.
2. `한국관광공사_지역별 관광 수요 강도` API의 활용신청을 합니다.
3. 개발계정 승인 상태와 Service Key 발급 여부를 확인합니다.

이 과정은 사용자 계정의 신청과 승인이 필요하므로 자동 완료할 수 없습니다.

## Step 9 — Swagger에서 확인할 항목

체류 강도와 소비 강도 기능을 각각 실행하고 다음을 기록합니다.

- 실제 Endpoint URL
- 필수 Query 파라미터 이름과 예시 값
- HTTP 상태 코드
- JSON 응답 여부
- 지역 필드명
- 체류/소비 강도 필드명
- 기준 시점 필드명

실제 확인 전에는 `.env`의 관광 URL과 Service Key를 더미 값으로 유지합니다.
